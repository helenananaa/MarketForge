# 策略主导的背景市场人数与分配

日期：2026-10-14。范围是一个现货及其对应永续，账户资金与库存有限，价格来自真实撮合。

背景市场现在以交易策略为主体。同一策略族按指标参数、K 线周期、资本规模、杠杆、持仓期限和退出规则实例化。噪声不承担主要交易。本轮增加了可配置的原生策略执行器和本地原版 Pine 策略入口，并使用无噪声人口进行了实际撮合。

人数先以 300–1,000 个实例作为完整策略生态的校准范围。100 个可用于行为归因，3,000 或更多要以周期细分、流动性集中和市场统计的改善为依据。本轮没有测出相对正常市场的最低人数，也没有把 1,000 当作已经完成的实盘相似性资格。

## 已实现的策略能力

`TechnicalStrategyTrader` 是正常内置注册器中的可配置 Rust bot，支持现货 long/flat 及单向持仓模式的永续 long/short。它不调用 Pine 解释器，沿现有账户预算、交易网关和撮合路径执行。旧 16 个冻结 NativePine 版本保持原有语义，作为独立对照；新执行器提供扩展能力。

| 类别 | 可配置策略族 |
| --- | --- |
| 趋势与平滑 | SMA、EMA、MACD、Hull、ALMA、SSL、SuperTrend、UT ATR、ADX、ROC、Ichimoku |
| 突破与波动 | Bollinger breakout、Donchian、Turtle、Keltner、Squeeze |
| 均值回归 | RSI、Bollinger reversion、CCI、Stochastic、StochRSI、Williams、WaveTrend |
| 量价 | VWAP reversion、OBV、MFI reversion |

共 26 族。每族只接受实际使用的参数，周期可为 1 秒到 1 天的整数仿真秒；默认生态同时安排 1 秒、5 秒、10 秒、30 秒、1 分钟和 5 分钟周期。短试验单独使用 1／5／10 秒，以保证预热可观测；长周期并没有被伪造历史或强制立即激活。

公共配置包括仓位上限、权益使用比例、目标杠杆、单笔上限、保护价格、信号延迟、止损、止盈、最长持仓时间及冷却。全策略共享权益回撤、追踪止损、波动和保证金风险覆盖。现货卖单受实际库存限制；永续反转先 reduce-only 平旧仓，实际平完后才开另一边。未成交和部分成交不更新为假想仓位。

状态绑定配置与账户身份，保存指标、闭合 bar 游标及保留窗口审计、待执行目标、实际成交游标和风险状态。重复观察不重复提交同一时点的动作，改变已提交历史或缺失游标拒绝执行。长期运行遇到私有成交窗口不再覆盖提交游标时仍需恢复／回放，不能据此宣称无限寿命资格。永续 hedge 双向账户暂由现有 Pine broker 路径处理，新原生执行器明确使用 one-way 账户。

实现：[执行器](../exchange-core/src/technical_trader.rs)、[指标与信号](../exchange-core/src/technical_signals.rs)、[人口生成器](../scripts/strategy_ecosystem.py)。

## 本地原版 Pine 与公式适配

本地档案中识别了 1,749 个含 strategy 声明与下单调用的文件，不等于 1,749 个已支持策略。许多 hasnocool 档案是网页转录，夹带说明、行号及 Expand 页脚。提取器保留原档案哈希、作者和许可注释，移除展示层并归一 NBSP／零宽空格，记录提取后代码的独立哈希。

按文件名行为类别、固定种子抽样 80 个原版，24 个在三种行情中运行、产生订单并通过抽样前缀检查。没有为通过测试删除它们的交易条件。其余保留拒绝原因：未来引用、额外数据依赖、尚不支持的函数／设置、无订单及解析问题。这是抽样资格，不是整个档案的兼容率。

[原版清单](strategy-ecosystem-originals.json)和 `bot-plugins/pine-strategy/scripts/ecosystem/originals/` 保存具名原版。26 个可配置公式另存于 `scripts/ecosystem/`，与原版区别命名。它们是公式适配，不能声称完整复制作者的过滤、加仓、退出和回测设置。

四类多空入场／退出信号在 26 族 × 3 组参数 × 6 类行情的 468 个对照中均与本机 Pine 0.3.1 对应公式一致；每例额外检查 157 根前缀。该证据比较信号，不是全指标浮点数、原版完整策略或利润的一致性证明。

原版实机测试通过正常进程插件、HTTP 调度、账户和撮合：D-Bot Alpha RSI 在现货买入并平仓；EMA SCALPEUR + RSi - SHORT 在永续开空并平仓，两个市场各实际处理 71 个闭合 bar。新原生执行器也在同一 HTTP 路径验证了现货交易、永续多空和反转。

实机暴露出的 Pine 支持缺口已补齐：编译器把命名参数绑定为固定 HIR 槽位，外部执行器现在从 builtin 签名恢复名称，正确识别 when、订单备注和告警展示参数。OCA 与立即执行等真实执行语义不会被当作备注忽略。补丁适用于进程插件的独立私有运行库和仓库内 Rust Pine 核心。

24 个原版目前均有离线资格，只有上述具名路径具有本轮 HTTP 成交证据；不要把另外 22 个直接叫作已通过 broker 实机资格。带外部数据、日期／会话条件、账户统计或特殊订单设置的原版要逐个接入验证。

## 无噪声人口与实际成交

候选按实例数分配如下。数量决定人口细分，资金和活动应独立设置。

| 角色 | 人数占比 | 1,000 bot 数量 | 职责 |
| --- | ---: | ---: | --- |
| 多策略与多周期交易 | 70% | 700 | 不同参数与周期的趋势、反转、突破、量价及波动交易 |
| 做市 | 10% | 100 | 有限库存、多档报价、异质报价与退场节奏 |
| 私人估值与配置 | 10% | 100 | 不同初始估值、较慢交易，提供与技术信号不同的需求 |
| 有限拆单任务 | 10% | 100 | 不同方向、起始时间、目标数量和期限的 TWAP 需求 |
| 噪声 | 0% | 0 | 本轮未使用 |

这不是对真实市场人数占比的测量。短试验的现金池固定为 10 亿内部货币单位，四类现金占比分别为 35／30／20／15%。现货初始库存另列，不能混同现金、权益、挂单深度或成交份额。各账户规模不等。人口变化同时改变参数／周期覆盖与预算细分，整数库存配置也有差异；这组数据不能解释为纯人数的因果效应。

使用已有冻结 native observation wave API 和真实网关运行，保持每个时点的观察与正常原生投递机制一致。研究运行器不修改生产调度或优化实现。每次 1,200 仿真秒，100／300 bot 各使用种子 7、19、41；1,000 bot 使用种子 7。

1,000 bot 真实产生现货 25,916 和永续 54,033 条逐笔撮合成交。700 个技术实例在结束时全部完成对应指标预热；1 秒流获得约 1,193–1,196 根非空闭合 bar，5 秒与 10 秒分别为 240 与 120 根。技术组贡献 45.84% 的双边成交参与量，maker 为 50.00%、私人估值 3.27%、执行 0.90%。100／300 组技术参与量均值分别为 46.05%／47.35%。每笔数量对 maker 和 taker 各记一次，因此不能将这些数字叫作主动成交份额。

1,000 组有 501 次拒单，主要是冻结观察后市场变化导致 post-only 报价会吃单。它们是交易所回执，未计为成交或隐去。无自成交，所有成交来自有限账户资金与库存。

永续聚合代理在秒级时钟上会把同秒同价同方向的连续成交合并，产生很强的方向交替表象。为此另用实际 taker_order_id 统计：1,000 组实际已成交主动单同方向连续比例，现货 0.560、永续 0.519。100 组分别约 0.577／0.502，300 组约 0.534／0.525。订单流目前接近短程随机基线，尚未表达真实拆单研究中的明显持续性；提高执行者的实际需求贡献、拉长策略持仓并分散反转／退出机制应作为下一轮组合校准变量。

增加人数提高成交密度，但没有降低所有波动。100 的密度已可用来研究策略互动，300 提供了更广的参数覆盖，1,000 让全部 26 族在本种子中实际交易。当前不应据此继续自动扩到 3,000／10,000，也不应声称 1,000 已像正常市场。需要把人数与角色贡献、深度、持仓时长、订单流和参赛者冲击一起校准。

原先串行研究路径的 1,000 × 1,200 秒尝试在 180 墙钟秒中止，失败保留。本表来自随后完成的现有 observation wave 路径，两条运行方式不混用。没有调整生产性能实现。

复现图表：`.venv/Scripts/python.exe scripts/plot_strategy_market.py --book-receipt .local/strategy-ecosystem-20261014/native1000-book.json`。

先在 300 和 1,000 的完整生态上固定总权益、可执行深度与目标流量，比较策略族资金份额和参数周期混合，再考虑 3,000。首轮不要把 70% 实例数写成必须 70% 成交量；应看哪类实际成交、持仓与退出占了市场。

现有执行任务在各自截止时停止，长期市场要有显式、有限预算的任务队列或再平衡需求，不能自动充值或用随机市价单补缺口。做市人数增加时拆分流动性预算，不能复制每个 maker 的全部深度。长期周期要用实际生成的历史预热，不能把未激活账户计入活跃人口。

验收至少同时包括多周期收益分布和相关性、波动聚集、趋势／回撤时长、盘口价差与深度、撤单／补给、角色实际贡献、资金耗损、成交集中度、可执行基差、以及参赛 AI 分层订单的冲击与恢复。没有真实盘口基准时，先制定产品接受目标，再用多日期、多状态的独立行情验证；二十分钟运行不能代替长期资格。

同一策略的参数和周期不同，确实可以形成短线与长线参与者，但仍可能响应同一信息而高度相关。因此应按实际信号、持仓、订单方向和退出时点聚类，测量有效多样性，避免把更多文件或更多实例当作独立动机数量。

## 使用与证据

### 第二轮：实际原版、长周期、做市来源和冲击分支

本地做市库存优先核查了 Hummingbot、hftbacktest、ABIDES-JPMC 和 Avellaneda 示例。没有按收益截图或仓库热度宣称“最好”。本轮选 Hummingbot 的 Avellaneda 库存风险报价和 hftbacktest 的 GLFT 系数／动态价差作为两类做市适配，在同一市场内比较旧策略与两类混合。ABIDES 的成交量参与式梯度报价保留为后续候选；Avellaneda 示例中的预设 Brownian 价格过程不作为这里的成交价格生成器。

- [Hummingbot 官方 Avellaneda 文档](https://hummingbot.org/strategies/v1-strategies/avellaneda-market-making/)：库存目标、波动与流动性估计、订单尺寸、撤单确认。该原实现官方标明现货 CLOB；本项目永续实现是账户／风控适配，不是其永续 connector 的复用。保存提交 `9af100d6822da7d2d0291a906c730ef172284ee2`，源码 `hummingbot/strategy/avellaneda_market_making/avellaneda_market_making.pyx`，SHA256 `2b093fdbf6150f3453809053f6694c0e3a66b4f35ca13633122be855250bb73e`，来源许可 Apache-2.0。
- [hftbacktest 官方 GLFT 教程](https://hftbacktest.readthedocs.io/en/latest/tutorials/GLFT%20Market%20Making%20Model%20and%20Grid%20Trading.html)：订单到达强度、波动、库存偏移和动态价差。保存提交 `5f3ec40b2afb764e0fea112f941ed85523ef4e88`，Notebook SHA256 `02393d6e09288b68654a800c6523c3a69d9f9b40aa2dd540d7f379ce162ffb2a`，来源许可 MIT。

新 `AdaptiveLiquidityMaker` 采用两类报价公式、实际账户库存／资金、微价格、不同风险参数、报价尺寸、刷新间隔、抖动、逐单寿命和确认后撤补；健康／不健康永续保证金通过现有预算及 reduce-only 保护。它没有完整复制上游 connector、订单优化或利润表现。强度估计使用完整闭合秒 bar 的交易价格包络，避免最后 32 条公开成交的截断；它是按观察间隔计算的触达代理，不是精确逐单／队列强度。无足够估计时保留标记过的先验，不把未校准账户算成已校准。公式单测与 JSON 状态恢复／共享观察对照通过。

原版预检：24 个离线候选中，11 个通过当前外部运行库的固定账户反馈与三个行情测试。其余拒绝原因保存在 `.local/strategy-ecosystem-20261014/round2/original-runtime-preflight.json`：原生回测执行设置、成交统计 API、风险 API 等。预检不是成交资格；正式混合匹配另按源码统计真实成交。会开空的原版被分配到永续，保持源码条件。原版 `quantize_strategy_orders=true` 显式启用交易所网格归一：限价买向下／卖向上，触发买向上／卖向下，数量向下到 lot，追踪距离向上到 tick。账户、成交和费用字段仍严格检查精确整数。该选项默认关闭，并保留旧默认状态身份；原代码条件、日期或过滤器没有为了出单而删除。

正式配比试验固定总背景现金 10 亿内部单位；300 人基准为技术 180、做市 30、私人估值 30、有限执行 45、噪声 15。噪声 0／5／10% 改变相应技术人数与组资金，是组合对照，不是只改变一个噪声概率的纯因果试验。旧做市／新做市的 5% 对照保持其他参与者、资金及初始库存相同；每个角色使用独立随机流，做市参数抽样不会改变后面角色的需求。拆单仍是有限父任务，起始时间分散在十小时内，不自动充值。
