# 现货＋永续历史样本参考

本轮保留 33 bot、同交易所现货与永续的结构，增加公共数据下载校验、统计、配方
映射和真实撮合回执比较。它是可复现的校准起点，当前配方没有通过真实市场相似性资格验证。

## 来源与时间切分

使用 [Binance 官方公共数据归档说明](https://github.com/binance/binance-public-data)
中的 BTCUSDT 2025-01-02 现货／USD-M 永续每日聚合成交及 2025-01 月资金费率。
这是固定历史样本，不代表当前行情。每个 ZIP 都校验官方 `.CHECKSUM` 的 SHA256。
整日校验了现货 1,299,165 条、永续 1,505,248 条聚合成交；统计只使用 UTC
00:00–01:00，前 1800 秒拟合，后 1800 秒留出比较。

现货该日时间戳是微秒，永续为毫秒，解析器分别转换。重复 ID、倒序时间、越界日期、
非有限价格／数量及重复来源直接失败。数量累计使用 Decimal，浮点仅用于统计输出。
一分钟成交量包括没有成交的秒；收益只比较相邻实际有成交的秒，不用未来成交补空档。
不足两个相邻收益样本时标准差输出 `null`，不能解释为零波动。

| 市场／指标 | 拟合 30 分钟 | 留出 30 分钟 |
| --- | ---: | ---: |
| 现货聚合成交／秒 | 18.207 | 22.763 |
| 永续聚合成交／秒 | 17.918 | 26.733 |
| 现货相邻活跃秒收益标准差，ppm | 69.612 | 99.245 |
| 永续相邻活跃秒收益标准差，ppm | 75.986 | 110.637 |

| 永续聚合成交数量中位数，BTC | 0.01000 | 0.00500 |
| 现货 taker 同方向连续比例 | 0.8590 | 0.8873 |
| 永续 taker 同方向连续比例 | 0.7706 | 0.8029 |
| 同秒末次成交价格基差中位数，ppm | -182.624 | -108.655 |

基差只取两边同一封闭秒桶内均有真实成交的样本。这不是可执行买卖报价，不可直接
推断套利收益。当前策略支持买现货、卖永续；负基差样本中保持观望符合该约束。

## 配方与比较

仅使用拟合段映射价格／数量尺度、噪声方向延续性、趋势阈值、风控波动阈值及合成
事件幅度。现货锚点设为 1,000,000 tick，数量单位为 0.001 BTC；资金按同一价格
尺度调整且仍然有限。内部 V/BTC 名称保留，单位转换写入 `mapping.json`。

报价宽度采用历史成交波动加模型手续费底线，属于假设；数据没有真实盘口。沿用
原有参与者数量、活动频率、延迟、库存目标与手续费。资金费率取拟合窗口内首条
实测记录（本样本 100 ppm、8 小时），没有拟合段记录时拒绝使用未来费率。
未模拟完整历史费率序列；消息仍是合成需求冲击。

用实际撮合运行种子 7／19／41，各 600 仿真秒，全部成交来自有限资金和盘口匹配：

| 指标 | 种子 7 | 种子 19 | 种子 41 |
| --- | ---: | ---: | ---: |
| 现货成交数 | 743 | 801 | 968 |
| 永续成交数 | 20 | 77 | 54 |
| 现货有成交秒数／600 | 394 | 385 | 450 |
| 永续有成交秒数／600 | 10 | 53 | 37 |
| 现货撮合成交／秒 | 1.238 | 1.335 | 1.613 |
| 永续撮合成交／秒 | 0.033 | 0.128 | 0.090 |
| 现货相邻活跃秒收益标准差，ppm | 743.278 | 917.603 | 874.708 |

当前现货成交密度远低于样本，价格跳变尺度明显偏高；永续更稀疏。种子 7 的永续
只有一个相邻活跃秒收益样本，标准差为 `null`。撮合逐笔成交与历史聚合成交的聚合口径不同，
运行时长也不同，因此比值只诊断差距，不能作为严格统计检验。不能只调价格单位就
声称已匹配真实市场。

后续联合搜索已经实现，见 [盘口反馈与永续动机](MARKET_MICROSTRUCTURE.md) 和
[2026-10-09 验证记录](validation/2026-10-09-market-microstructure.md)。本页上表保留
第一轮原始结果；新研究运行器、数量尺度和聚合口径在新记录中单独说明。
仍需用更多日期和行情状态留出检验。真实价差、撤单率、队列位置和网络响应需要另加
盘口与订单事件数据，当前成交归档不提供这些信息。

## 复现

```powershell
.venv/Scripts/python.exe scripts/calibrate_behavior_market.py
cargo build -p exchange-core --example behavior_market
.venv/Scripts/python.exe scripts/compare_behavior_reference.py
$env:PYTHONPATH = "$PWD\python"
.venv/Scripts/python.exe -m unittest discover -s python/tests -p test_market_calibration.py -v
```

默认输出 `.local/market-calibration/`：官方来源与校验和、`reference.json`、
`recipe.json`、`mapping.json`、每个种子的 `simulation-*.json` 和 `comparison.json`。
原生例子支持 `behavior_market.exe <seed> <recipe.json 或 -> <steps>`；省略参数继续
使用原配方和 300 步。比较报告包含所有收益样本数、活跃秒数、拟合／留出残差及限制。
