# 现货与永续绑定

创建房间时，在永续市场配置中明确指定现货来源：

```json
"price_link": {
  "spot_instrument_id": "V-BTC-SPOT",
  "max_age_ms": 30000
}
```

来源必须是同一交易所、相同 base_asset 和 quote_asset 的现货市场。一个现货可供多个永续使用。不存在的来源、永续作为来源、资产不匹配、跨交易所来源和零有效期都会拒绝建房；不按名字猜测配对。

现货最优买卖两侧都有效时，指数价取中间价，向下取整到整数 quote 单位。盘口不足两侧时，可以回退到有效期内的最近现货成交价。永续标记价取指数价，并向下对齐永续 tick_size；最低一个有效 tick。价格字段已经是 quote 单位，tick_size 是价格增量，不是价格乘数。

现货最优档价格或数量变化、以及真实成交会更新指数。无效订单、撤销不存在的订单、只改变深层盘口的操作不会刷新行情有效期。max_age_ms 使用房间仿真时间，默认 30000 ms。

联动更新与原始现货命令一起提交或一起回滚。它即时刷新永续未实现盈亏、保证金状态和同 quote 资产的全仓风险，RoomManager 随后执行现有自动强平。联动回执附在原命令的 price_updates 中，不额外消耗命令序号；恢复从原命令确定性重建联动，并核对回执。快照保存指数、标记价、来源时间和最近现货成交。

行情状态：

| status | 含义 |
|---|---|
| awaiting_price | 尚无有效现货指数，初始标记价只用于初始化 |
| live | 有效现货指数 |
| stale | 最后一次有效来源已超过有效期 |
| unavailable | 当前现货盘口不足，且没有有效成交可回退 |

行情过期或不可用时，保留最后有效指数与标记价，不重新锚定。新提交的非 reduce-only 永续订单及改单被拒绝；撤单、reduce-only 订单和已有强平流程继续可用。已存在的挂单没有新增撮合暂停规则。绑定永续不能通过 mark-price 接口手动覆盖标记价。未绑定永续保留原来的独立标记价行为。

永续的订单簿、成交记录和 K 线仍由其真实订单撮合产生，因此永续成交价可以高于或低于现货指数。DynamicMarketMaker 在绑定永续上以现货指数作为报价中心，通过实际撤单、挂单跟随现货；指数无效时撤去自己的报价。该行为只适用于明确绑定的市场。

## 使用

网页“创建仿真市场”默认勾选“绑定永续”：建立现货及绑定永续，启动原有 20 个现货背景交易者和 3 个独立账户的永续做市商。下拉框切换交易品种，下单按当前品种路由。永续页面显示现货指数价、标记价及来源状态。取消勾选可使用原现货配方。

```powershell
python scripts/linked_market.py --room linked-demo
python scripts/linked_market.py --dry-run
python scripts/linked_market.py --export scripts/fixtures/linked_market.json
```

AI arena 新房间也配置现货与永续绑定；它仍只有有限初始流动性，不自动增加背景交易者。已有房间不迁移，使用新房间名称创建绑定市场。

API 的 instrument view、ticker 和 observe 返回可选的 perp_price；订单回执、房间执行记录和公共事件流包含 price_updates。这些新增字段只包含公共行情，不含其他账户信息。未绑定市场保持兼容。

本版是同交易所的单现货指数绑定，标记价直接跟随指数。可启用[资金费周期结算](FUNDING.md)；新绑定配方已经启用。没有新增多交易所加权指数、标记价基差平滑或自动套利交易者。
