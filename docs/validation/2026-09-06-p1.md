实际变更和契约：
- 新增 `ParticipantObservation` v1：公开盘口/成交、仿真时间、自己的订单与账户；Noise/DCA/Grid 全部改用该边界。Agent 必须设置 `instrument_id`。
- 新增权威 `SchedulerState` / `run_scheduler_step`：先推进房间时钟，再按 `participant_id` 排序观察/决策/提交。暂停时外部 NewOrder 拒绝，调度器仍可手动单步。`POST /rooms/{id}/clock/step` 仅 paused + admin。
- 版本化 agent 状态（RNG / DCA observed_steps / Grid seeded）与未完成动作；崩溃点 Before/After decision persist、action submit、step complete，恢复后与不中断 twin 一致。
- Worker 不再 HTTP 自回调；`commit_scheduler_step` 走 journal-then-install，并写入 `RoomMutation::SchedulerProgress`。Bearer 模式可启动 worker。
- Worker lifecycle：running / paused / recovering / failed / stopped。接管恢复 scheduler 状态。
- Migration 0013：`marketforge_control_idempotency` 表；pause/manual-step 幂等目前写入进程内 map（同进程重试有效）。
- 时钟过大 steps / overflow：`ClockError`，`MAX_CLOCK_ADVANCE_STEPS=10000`。
