## 验收边界

- PostgreSQL 条件测试在没有配置数据库时可提前返回；本轮没有重新执行 PostgreSQL 故障矩阵。恢复证明来自核心快照和服务器确定性日志用例。
- 网页图表仍是原有占位图，不能作为真实 K 线证据。初始默认 API URL 指向原有服务时产生的两个 CORS 错误保留在浏览器历史中。
- 测试与 Clippy 对应运行时工作区；其他聊天正在同仓库修改 WebSocket、Pine 和工作台功能，其后续变更需各自验收。
- 新配方仅影响新房间，已有房间不会自动迁移。资金费是明确记录的仿真模型，未新增自动套利、跨交易所指数、交易所专属溢价算法或基差平滑。
- 资金费金额采用现有整数 quote 单位，小额费用可能为零，未实现跨周期小数尾款。
