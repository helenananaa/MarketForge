实现 commit / diff 标识：本 P5 提交
实际变更和契约：
- 角色矩阵 `owner|admin|instructor|trader|spectator` 作为写权限执行；instructor 不是任意账户交易；spectator 不能下单或订阅私有流。
- HTTP `POST /rooms/{id}/members`、`POST /rooms/{id}/members/{user_id}`、`POST /rooms/{id}/accounts/{account_id}/owners`；移除成员同时删除 account_owners。
- 训练开始后账户分配冻结（409）。
- `strategy.v1`：`GET /rooms/{id}/observe` 返回 `ParticipantObservation`；非 admin 每仿真步最多 8 个动作（429）；非法 price/qty 返回 400。
- Python SDK `python/marketforge`：observe/place/cancel/idempotency/cursor/trusted owner。
- 示例策略 `python/examples/buy_remaining.py` 对同一训练房间观察并在 ask 成交。
- `scripts/batch_runner.py`：按 seed 隔离房间、`--state` 按 run 恢复、失败 run 保留。
- 训练启动后推进 `next_order_id`，避免 seed 订单 ID 与学员首单冲突。

执行环境：loopback 内存服务器 `127.0.0.1:57313`/`57314`；Postgres `127.0.0.1:55432`。

- 无新 SQL 版本；复用 `marketforge_room_members` / `marketforge_account_owners`。

兼容/迁移影响：无新 migration。Observation 协议版本 `strategy.v1`。account_owners 内存结构改为多用户集合。
