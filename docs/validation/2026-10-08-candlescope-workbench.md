## 生产页面真实闭环

页面来源 `http://127.0.0.1:15173`，后端 `http://127.0.0.1:57305`。

| 路径 | 实测结果 |
| --- | --- |
| UI 创建背景房间 | `cs-workbench-20261008` 创建成功，20 个背景参与者运行，真实成交生成 K 线 |
| UI 市价买入 | 后端撮合回执成功，账户现金与持仓随后端观测更新 |
| 确定性房间买入 | 无参与者测试房间 `cs-deterministic-20261008` 买入 1 lot，现金 10000 → 9898，持仓 20 → 21 |
| 限价挂单与撤单 | 1 tick × 2 lot 冻结现金 2；撤单后挂单消失，冻结现金归零 |
| 风险拒单 | 100 tick × 1000000 lot 被 `InsufficientCash` 拒绝，余额保持 9898；UI 不将 actor 的 accepted 当成订单成功 |
| 暂停/继续 | 后端状态更新；暂停时 UI 禁止新买卖 |
| 有调度器单步 | 暂停背景市场的步数 975 → 976，HTTP `/clock/step` 成功 |
| 无调度器单步 | 后端明确 409 拒绝调度步骤后，调用 `/clock/advance`；步数 0 → 1，市场时间 0 → 1000 ms |
| 权限失败 | 未授权用户观测返回 403，UI 标记错误并禁用交易；原用户重新连接正常 |
| 周期切换 | 1m 切换与返回 1s 正常，读取真实后端蜡烛 |
| 原生导出 | 导出面板生成 2048 × 1300 PNG 预览；未验证所有格式或 OS 保存对话框 |
| 主题与小屏 | 明暗主题正常；390 × 844 图表及交易区无横向溢出；复查并修复图表裁切及工具栏越界 |
| 启动脚本 | 复用已运行后端，实际启动生产前端，等待页面可用后返回地址；后端冷启动分支未单独验收 |
