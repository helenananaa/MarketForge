# Native Pine main integration and ignored samples

The sixteen native Rust bots and their scheduler, timing and benchmark support
are integrated on top of main `05ce347478f9b870996e74ac66c9afc7a980b27e`.
Downloaded strategy corpora and generated `native_*.pine` samples remain local
and are excluded by the repository `.gitignore`; research tools, metadata,
Rust implementations and tests are versioned.

To remove hidden dependencies on ignored samples, the test helper reconstructs
the thirteen extended Pine references from the catalog's fixed formulas and
predicates. It verifies both original formula and diagnostic-script SHA-256
hashes. Differential tests use those sources in memory; HTTP tests install them
into a disposable plugin directory. The generated bytes match all thirteen
existing local samples exactly. No downloaded source corpus is required.

## Checks for this integration

- `cargo test --workspace --all-features`: **793 passed, 23 explicitly ignored,
  zero failed**. Eleven PostgreSQL tests actually ran with
  `MARKETFORGE_REQUIRE_POSTGRES_TESTS=1` and a disposable loopback database.
- Whole-workspace Clippy, all targets and features, with warnings denied; Rust
  formatting and staged whitespace checks passed.
- A clean export of the staged index contains no generated Pine samples or
  downloaded libraries. Its manifest and benchmark recipe suites passed all
  ten tests; reconstruction validates all thirteen frozen reference hashes.
- Eight differential tests passed from that export using the current release
  probe: the original three ports' five tests, thirteen-reference manifest,
  plus MACD's six-regime 768-bar matrix and 65 large-price rolling-restoration
  comparisons. `MARKETFORGE_NATIVE_PINE_CASE=native_macd.pine` deliberately
  limits the new extended runtime comparison to MACD in this check.
- One focused live check used the generated temporary MACD plugin against the
  native MACD bot for 128 bars. Accounts, orders, books and trades matched;
  both bought and sold. PostgreSQL restart after bar 64 preserved responses,
  observations and duplicate-step idempotency. Trade evidence is accumulated
  across observations because the public trade list is a bounded window.

Logs, generated HTTP receipt, clean-index differential receipts and the index
export are retained under `.local/main-cleanup-20261014/`. The test server and
the PostgreSQL cluster started for this validation are stopped after checking.

This integration does not rerun the full thirteen-strategy HTTP matrix or
thousand-bot performance measurements. The dated October 13 reports retain
their original snapshot's hashes, broader formula/HTTP evidence and measured
performance; those numbers are not claimed as current-main measurements.
